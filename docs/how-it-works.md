# 工作原理

你用自然语言提问，智能体按 skill 的规则问清情况、调用内置的计算脚本，再把结果解读成回答和交互盘面。
你不需要接触脚本，下面说明 skill 在背后做了什么、按什么口径算。

## 计算交给代码，解读交给模型

大模型擅长问询和解释，却不擅长排盘、推算干支节气，这类错误「看起来对」，最难发现。所以：

- **代码负责**：排盘、历法、查表。结果是确定的，有回归测试，测试用例取自可公开核对的结论。
- **模型负责**：问清信息、解读结果、写批注。旺衰、用神、形峦吉凶这些属于判断，必须说明依据与所依流派。
- **说法要有出处**：每条规则、引文都登记了出处与核对状态（原文已核对、已计算验证、公认出处、流派口径、已删除），
  模型按状态措辞，不把通行做法说成经典原文。见 [风水出处](../skills/fengshui-master/references/sources.md)、[八字出处](../skills/bazi-mingli/references/sources.md)。

## 三个 skill

| skill | 负责 | 交付 |
|-------|------|------|
| `fengshui-master` | 看宅（玄空飞星、八宅、形峦）、择日、煞气、风水问答，按喜用五行配合风水 | 回答 + 可「起盘」的飞星盘 |
| `bazi-mingli` | 排八字、五行喜用、大运流年、桃花贵人等神煞 | 先白话后专业的回答 + 交互命盘 |
| `city-wuxing-map` | 城市全域五行着色 | 真实底图上的交互地图 |

三者都在 `skills/` 下，可以分开安装。八字与风水交叉时（如按八字布置卧室），由八字 skill 给出喜用五行，风水 skill 给出方位与命卦。

## 各项怎么算

| 计算 | 口径 |
|------|------|
| 玄空飞星 | 二十四山玄空阴阳、同元龙定顺逆；支持替卦，提示兼向与空亡；判定旺山旺向、上山下水、双星、伏反吟、合十、三般卦。元运以入住或大修时间、立春为界 |
| 八宅 | 依《八宅明镜》游年歌诀；命卦按立春分年，男五寄坤、女五寄艮 |
| 流年流月 | 紫白飞星、太岁、岁破、三煞、五黄二黑方 |
| 择日 | 干支、节气、建除、黄黑道、神煞、宜忌取自历法库；月破、正四废、冲当事人直接排除；岁破日、受死只作提示 |
| 八字 | 年月柱按同一时刻的北京时间比对立春与节气，日时柱用出生地真太阳时；自动扣夏令时（如大陆 1986–1991 年）；子时默认 23:00 换日并列出另一说；支持农历、时辰不详、海外出生 |
| 八字查表 | 藏干十神、十二长生、月令司令、旺相休囚死、合冲刑害、禄刃贵人驿马咸池空亡，依《三命通会》；调候按日干与节气月检出《穷通宝鉴》原文。不判定旺衰、用神 |
| 城市五行地图 | 1km 统计格网裁切真实城市边界，土地覆盖与城市功能两种口径逐单元分类，标注来源与置信等级。详见[分析方法](../skills/city-wuxing-map/references/method.md) |

## 交互盘面

每次排盘都生成一个单独的 HTML 文件，离线可开，适配手机与深色模式。盘面上的数字、干支、关系全部来自计算结果，模型只往里写批注文字。

- **飞星盘**：二十四山罗盘与九宫，「起盘」按洛书轨迹逐宫飞布，分层看运盘、山星、向星、流年，点宫看批注。[示例](examples/feixing-demo.html)
- **八字命盘**：「一眼看懂」白话总结与事实卡，术语点开有白话解释，柱间弧线标合冲刑害，大运流年可拖动。[示例](examples/bazi-demo.html)
- **城市五行地图**：真实底图上连续着色，点击单元看主象、兼象、理由、来源与置信度。[伦敦](examples/london-wuxing.html) · [纽约](examples/new-york-wuxing.html)
