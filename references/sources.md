# 出处与核对状态

本 skill 用到的每一条规则、引文都应能在这里找到出处与核对状态。**不在本表中的说法不要使用。**
发现错误请提 issue 并附出处（典籍、卷次、原文），确认后会同步更新本表与测试。

## 核对状态

| 标记 | 含义 |
|------|------|
| ✅ 原文已核对 | 取得原文，逐字核对过（版本见下方「所用文本」） |
| 🧮 已计算验证 | 古法规则按原样实现，与本项目公式 / 独立数据源逐项对照一致（见测试） |
| 📖 公认出处，原文未核对 | 出处为业内公认，但本次未取得原文，引文以通行本为准 |
| ⚖ 流派口径 | 无单一经典出处，或各派说法不一；使用时须说明「此为某派 / 通行做法」 |
| ✂ 已删除 | 现代或民间说法，查无经典出处，已从参考资料中移除 |
