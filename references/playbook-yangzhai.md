# 看宅：阳宅分析流程

适用：房子、办公室的布局、方位、摆放，坐向与旺衰。先读完本文件再作答。

## 一、分析流程

**必要信息**（逐步收集，不要一次问太多）：

1. 朝向：最好是罗盘/手机指南针读数（站在门内向外量，或量主要采光面）。说明手机需远离金属、校准后读数
2. 入住或大修完工时间（定元运）
3. 户型：大门、厨卫、主卧、客厅等各在宅中心的哪个方位（八方或中宫）
4. 外部形势：门前、背后、左右的道路、高楼、空地
5. 可选：家人的出生日期与性别（命卦，可多人）；想改善哪方面

**分析步骤**：

```
1. feixing --facing <度数> --year <入住时间> --annual <今年>
     [--rooms "大门=南,主卧=西北,厨房=东"] [--member "我:1985-03-01:m" --member "太太:1990-06-01:f"]
   （先看文字盘；给了户型与家人时，脚本会列出每个房间所在宫的星曜、宅卦与各人命卦的八宅吉凶）
2. 只问八宅时可用 bazhai --facing <度数> [--birth ... --gender ...]
3. 若脚本提示兼向/空亡：说明不确定性，必要时 --tigua 两盘并参
4. 结合户型：逐个房间看脚本列出的对位结果；当令向星宫位看是否有门/开阔处，当令山星宫位看是否有实墙/靠山
5. 结合外部形势判断山水是否配合格局
6. 给出：可操作的调整建议 + 流年注意
7. 把解读写成批注 JSON，再带上同样的 --rooms / --member 跑一次 feixing ... --html <路径> --notes <批注.json>
   生成交互盘面（见本文件「二、交互盘面」）
```

**输出格式**：

```
【宅基信息】坐向、度数、元运
【交互盘面】链接（file:// 绝对路径或已发布的网址），一句话说明怎么看
【飞星盘】直接引用脚本输出的九宫格
【格局判断】
【各房间要点】大门、主卧、厨卫等所在宫的星曜组合与八宅吉凶（以脚本的房间对位结果为准）
【八宅参考】宅卦、命卦、配合
【建议】具体、可操作，移形易位优先
【流年注意】
```

## 二、交互盘面

凡排飞星盘，**默认同时生成 HTML 盘面**，并在回答中给出链接。页面由脚本绘制：九宫、二十四山罗盘、坐向线、「起盘」动画、逐宫批注；
给了 `--rooms` 时房间做成竹签插在对应宫位，用户可拖动或在签筒里取放，点签看这个房间；给了 `--member` 时可切换看宅卦或各家人的八宅吉凶。
单个文件、离线可打开、适配手机与深色模式。

1. 先把你对此盘的解读写成批注 JSON（只写解读文字，星数一律由脚本给出，不要写进批注里自行编造）：
   ```json
   {"summary": "总断，一两段",
    "palaces": {"离": "向首这一宫的批注", "坎": "……"},
    "rooms": {"主卧": "针对这个房间（在它现在的方位）的批注", "大门": "……"},
    "advice": ["可操作的建议 1", "建议 2"]}
   ```
   `palaces` 的键为宫名：坎 坤 震 巽 中 乾 兑 艮 离；`rooms` 的键与 `--rooms` 中的房间名一致；没有要说的可以不写。
   批注同样遵守「说法要有出处」。
2. 运行 `feixing ... --html <路径> --notes <批注.json>`。路径放在用户的当前工作目录（不要放临时目录或 scratchpad；批注 JSON 可以放临时目录），文件名如
   `飞星盘-8运-子山午向.html`（不给路径时脚本按此规则写到当前目录）。脚本最后一行打印生成的绝对路径。
3. 在回答里给出链接：`[打开交互盘面](file:///绝对路径)`，并用一句话说明可点「起盘」看飞星逐宫飞布、点任一宫看批注。
   若当前环境可以发布网页（例如有 Artifact 一类的工具），可以把该文件发布后给出网址。
4. 用户补充信息（户型、外部形势）后改了解读，重新生成同一路径的页面即可。

其他类型（择日、八字、起卦）的页面在路线图中，尚未提供；八宅吉凶已作为飞星盘的一个图层。

## 三、形势峦头（体）

**龙**：来龙脉络，山脉走向与气势
**穴**：结穴之处，气聚之点
**砂**：四周护卫之山（青龙/白虎/朱雀/玄武）
**水**：来水去水，水口收放
**向**：立向，决定纳气方向

「龙穴砂水向」五诀见赵九峰《地理五诀》📖。

经典原则：
- 《葬书》内篇 ✅：「葬者乘生氣也」「氣乘風則散，界水則止。古人聚之使不散，行之使有止，故謂之風水」「風水之法，得水為上，藏風次之」
- 来龙宜连绵有力、去水宜有关锁：形家通说 ⚖
- 都市阳宅：道路、低平开阔处作水论，高楼、实墙作山论——现代类比 ⚖，向用户说明是类比

形峦是脚本算不了的部分，需要靠问询（门前是什么？背后是什么？左右高低？）。

## 四、玄空飞星（理气）

出处：排盘规则依《沈氏玄空学》📖（原文未核对）；由此排出的各运格局与公认结论一致 🧮。

**元运**：三元九运，每运 20 年，1864 年起一运；**九运 2024–2043**（以立春为界）。宅以入住或大修完工时间立极定运。

**飞星盘**：
- **运盘**：当运之星入中，顺飞
- **山星**：运盘坐山宫之星入中，管人丁健康
- **向星**：运盘向首宫之星入中，管财禄
- **顺逆规则**（常见错误，务必以脚本为准）：入中之星若为 n，到 n 的原宫，取与坐山（或向首）**同元龙**的那一山，按**玄空二十四山阴阳**定顺逆（阳顺阴逆）；n 为 5 时以坐山（或向首）本身阴阳论。
- **玄空二十四山阴阳**不同于八字地支阴阳：坎离震兑四正宫「地元阳、天元人元阴」（如壬阳子阴癸阴），乾坤艮巽四隅宫「地元阴、天元人元阳」（如丑阴艮阳寅阳）。
- 兼向超过约 3° 时多用**替卦**（`--tigua`），各派界限不一，宜两盘并参；落在两山交界（空亡）宜复测。

**格局**（脚本自动判定）：
- **旺山旺向**：当令山星到坐、向星到向——宜坐后有山、向前有水
- **上山下水**：当令山星到向、向星到坐——山水颠倒，峦头配合得宜（向前高、坐后低）亦可补救
- **双星到向**：宜向前有水又有山（如水外有楼）
- **双星到坐**：宜坐后有山又有水
- 另有伏吟、反吟、合十、父母三般卦、连珠三般卦

**九运旺衰**（⚖ 常用口径，各派细节略有出入）：
- 9 当令旺星；1 生气、2 次生气（未来旺）；8 退气（余气尚存）；7 衰气；3、4、6 死气；5 五黄煞
- 九运下卦二十四山皆为「双星到向 / 双星到坐」，无旺山旺向，峦头配合尤为重要

**常用断法**：
- 当令向星所在宫宜见水（开阔、门、走道、窗外低平），当令山星所在宫宜见山（实墙、高柜、外部高楼）——
  《青囊序》✅「山上龍神不下水，水裡龍神不上山」，蒋大鸿传：「山管山、水管水」
- 旺星受制（向星遇山、山星遇水）主相应失利——同上
- 五黄所到宜静不宜动、二五交加主病——《紫白诀》📖，只说明隐患，不展开断语

## 五、八宅明镜

出处：《八宅明镜》📖（原文未核对）；命卦公式与三元起例逐年一致 🧮，游年表满足对称与东西四分组 🧮。

**命卦**（以立春为界定年；脚本已处理 2000 年后与立春前出生）：
- 男命：(11 − 年 mod 9) mod 9，0 作 9；得 5 寄**坤**（2）
- 女命：(年 mod 9 + 4) mod 9，0 作 9；得 5 寄**艮**（8）
- 例：1985 男 = 6 乾；1990 女 = 8 艮；2000 男 = 9 离；1990-01-20 出生按 1989 年计

**东西四命/宅**：东四 = 坎、离、震、巽；西四 = 乾、坤、艮、兑。宅卦以**坐山**所在宫论（门朝东 = 坐西 = 兑宅）。

**房间安排**（主卧、书房放吉方，厕所、储物放凶方）：现代应用 ⚖，向用户说明是通行做法。

## 六、常见煞气与化解

**外煞**（形煞）：下表煞名为近现代港台通行术语 ⚖，处理思路为常识性建议，不是典籍规定。

| 煞名 | 形态 | 处理思路 |
|------|------|------|
| 路冲 | 道路直冲大门 | 改门位/门向最佳；次以玄关、屏风、绿植缓冲 |
| 天斩煞 | 两楼间窄缝正对 | 窗帘遮挡、少开该窗 |
| 壁刀煞 | 邻楼墙角切向本宅 | 遮挡视线（窗帘、绿植） |
| 反弓煞 | 弯道弓背对宅 | 难化，择宅时回避；高墙、绿篱遮挡 |
| 尖角煞 | 尖角冲射 | 遮挡视线 |

**内煞**：

| 问题 | 表现 | 处理 |
|------|------|------|
| 穿堂 | 大门直对后门/大窗 | 玄关、屏风阻隔 |
| 厕所压旺星 | 当令向星宫位设厕所 | 保持洁净、关门、通风 |
| 床头靠厕 | 床头墙另一侧为厕所 | 移床 |
| 横梁压床 | 梁正压睡眠区 | 移床，或吊顶遮盖 |
| 镜对床 | 镜子正对床 | 移开或遮盖 |

**原则**：化煞以「移形易位」优先——改动空间格局强于任何摆件。不推销、不强调必须购买的物件。
