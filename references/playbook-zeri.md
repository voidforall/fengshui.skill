# 择日流程

适用：搬家、入宅、开业、动土装修、嫁娶、安葬等选日子。先读完本文件再作答。

## 一、分析流程

**必要信息**：事项、日期范围、当事人出生年（多人可多个）、地点（若涉及方位/动土）。

```
1. zeri --event <事项> --start ... --end ... --birth-year ...
2. 对前 2–3 个候选说明理由与注意（凶煞、冲煞方）
3. 若涉及动土装修：说明年家煞方（太岁/岁破/三煞/五黄），避免在这些方位动工
4. 入宅可配合宅主命卦生气方、或吉时（可用 day --date "YYYY-MM-DD HH:MM" 查时柱）
```

## 二、择日要点

择日以《钦定协纪辨方书》为正统（📖 原文未核对）。规则细节与出处见规则资料 zeri.md（已在分流时一并读取）。

- 月份以**节气**为界，不是农历初一
- 大忌（脚本排除）：月破、正四废（《协纪》📖，与 lunar-python 逐日一致 🧮）；日支冲当事人生年地支；黄历明忌
- 通书俗忌（脚本标 △，不排除）：岁破日、受死——向用户说明这是通书做法、无《协纪》出处，由用户决定
- 年神方位：太岁、岁破、三煞、流年五黄方忌动土（《协纪》年神方位 📖）
- 吉神：只说明当日有哪些吉神、凶煞，不要说「某吉神可解诸凶」
- 婚嫁传统以合婚为先，择日次之；安葬以形势为本（《葬书》✅「葬者乘生氣也」）

脚本 `zeri` 会做排除并给候选打分（打分权重是本项目的筛选启发式 ⚖）；你负责解释取舍、结合事项与方位，必要时用 `day` 查单日细节。日期不得凭感觉写「约」某日。
