# 八字流程

适用：排八字、日主强弱与喜用、「我五行缺什么」、大运流年、事业财运婚姻等倾向、神煞（桃花、驿马、贵人），
以及八字配合风水（旺方、卧室书桌方位）。先读完本文件再作答。

八字在本 skill 中是辅助：结论宜谨慎，只说倾向，不说「命中注定」。

## 一、问询：先把出生时间问准

时柱错一个时辰，十神、大运起运都会变。排盘前问清：

| 要问 | 为什么 | 对应参数 |
|------|-------|---------|
| 出生日期：公历，或农历（问清是否闰月） | 农历由脚本换算，不要自己换 | `--birth`；农历加 `--lunar`，闰月再加 `--leap` |
| 出生时间：当时钟表上的时间，几点几分 | 不知道就只给日期，脚本排三柱 | `--birth "YYYY-MM-DD HH:MM"` 或只写日期 |
| 性别 | 大运顺逆 | `--gender m/f` |
| 出生城市 | 经度定真太阳时；海外要时区 | `--longitude`（东经为正、西经为负）；海外加 `--tz America/New_York` 之类 |

- 城市的经度可以按常识给出（如上海 121.5、北京 116.4、广州 113.3、成都 104.1、乌鲁木齐 87.6），说明是城市中心近似值。
- **夏令时不用问、也不要自己扣**：脚本按时区数据库自动处理（中国大陆 1986–1991 年夏季钟表快一小时）。用户说「已经减过一小时」时，把减之前的钟表时间给脚本。
- **23 点后出生**：脚本默认 23:00 起换日，并列出另一派（晚子时日柱不换）的日柱、时柱。向用户说明两说并存；用户或家里一直按另一种排，就加 `--zi same`。
- 用户只说「早上」「半夜」这类时段时：先按日期排三柱，再说明时柱有哪几种可能，不要替用户挑一个时辰。

## 二、排盘

```bash
python3 scripts/fengshui.py bazi --birth "1990-06-01 08:30" --gender f --longitude 116.4 \
        [--tz Asia/Shanghai] [--zi next|same] [--year 2027] --html <路径> [--notes 批注.json]
```

- 默认就生成交互命盘（`--html`），写到用户当前工作目录。问「某年怎么样」时加 `--year 年份`，盘面和文字都会落在那一年。
- 输出里都是计算或查表的事实：四柱、十神、藏干（本气、中气、余气及十神）、十二长生、纳音、旬空、月令司令（《三命通会》人元司事）、
  通根、透干、原局合冲刑害、五行个数、查表神煞、《穷通宝鉴》调候原文、起运、十步大运及其中的流年、关注年份的流年。
- **这些一律以脚本为准**，不要自己推干支、节气、十神，也不要补脚本没给的神煞。
- 输出开头若有「⚠」提示（23 点后出生、时辰不详、当日交节等），回答时必须告诉用户。

## 三、论命：判断要写出依据

旺衰、格局、用神不由脚本给出，是你的判断。按下面顺序看，每一步写出依据，并说明所依之书或派别：

1. **调候**：先读脚本给的《穷通宝鉴》原文（按日干、月令检出）。引用时照录原文，不要把它改写成原文没有的「用某某」。
   原文标为「季论」的，表示书中本月没有专段，只能参考一季总论。
2. **月令**：月支、司令之神、日干在月令的十二长生（临官、帝旺为得令）。
3. **通根透干**：日干在哪几支有根，根是本气还是余气；哪些十神透出。透而有根者力量才实（此为子平通行看法）。
4. **燥湿寒暖**：夏月燥、冬月寒，局中有无调剂。《滴天髓阐微》任氏命例很重视这一点：如「春时虚土，非比六九月之实」，
   不能只按「得令、得地、得助」打分定强弱。
5. **合冲**：合而化须有条件（化神当令、透出），脚本只标合，不标化。三合只见两字的，按《三命通会》不成局。
6. **格局与从化**：日主无根、全局一气或一方极旺时，要考虑顺其气势（从格、专旺），不要机械地扶弱抑强。
   反过来，日主有根就不要轻言从格。
7. **定用神**：明确写出「用神：某」。只有一个主用神，其余写成喜神、忌神，不要把主用神降成喜神。
   调候用神与扶抑用神不同时，两者都写出来，说明此盘以哪个为先、为什么。
8. **派别分歧**：调候派、扶抑派、格局派结论不同时，并列写出，不要强行统一。

## 四、按用户问的问题作答

| 用户问的 | 怎么答 |
|---------|-------|
| 「我五行缺什么」 | 先给脚本的两组个数（天干地支、藏干），说明「缺」只是字数上没有，不等于需要补；再按第三节判断，给出喜用。 |
| 喜用神、旺衰 | 按第三节完整论述。 |
| 今年、某年运势 | 用 `--year`。看流年干支的十神、与原局和所行大运的合冲刑害，再结合喜忌说倾向。不说具体灾祸，不说「必有」。 |
| 大运走势 | 按脚本的十步大运逐步说：干支十神、日干长生、与原局关系，再结合喜忌。 |
| 事业、财运、婚姻 | 只按十神和喜忌说倾向（如财星为喜、运行财地）。婚姻不说「克夫」「克妻」「婚姻必破」。 |
| 健康 | 只说五行偏枯的传统说法，并建议就医，不作诊断。 |
| 桃花、驿马、贵人、空亡 | 用脚本的查表结果，并转述《三命通会》「见生旺者未必便作吉论，见休囚死绝未必便作凶言」：神煞不单独定吉凶。脚本没列的神煞，说明本 skill 未核对出处。 |
| 八字配风水 | 喜用五行 → 方位、五色（五行方位、五色见规则资料 wuxing-ganzhi.md；不给「材质」建议，查无出处）。命卦是八宅的另一套方法，两者冲突时说明是两种体系，以实际居住条件为先。 |
| 合婚、起名 | 本 skill 没有核对过出处的合婚、起名规则，也没有计算。可以讲原理，要说明是通行说法，不下「不能结婚」之类的结论。 |

## 五、交互命盘

排了八字就默认生成命盘。四柱以卡片依次翻开，柱间弧线标合冲刑害，点任一干支看通根、透干、藏干与关系；
下方大运流年可点选或拖动，落到某一年就显示该年与原局的关系。

你的解读写成批注 JSON，用 `--notes` 传入（所有字段可选，只写文字，不写干支计算）：

```json
{
  "basis": "调候依《穷通宝鉴》四月丁火条；旺衰按子平月令、通根、透干",
  "summary": "总断：旺衰、格局、用神及理由",
  "pillars": {"年": "……", "月": "……", "日": "……", "时": "……"},
  "dayun": {"戊寅": "这步大运的看法"},
  "years": {"2026": "这一年的看法"},
  "advice": ["一条建议", "……"]
}
```

生成后，**回答的开头必须给出链接**：`[打开命盘](file:///脚本打印的绝对路径)`，并用一句话说明可点干支、拖动年份。

## 六、表达边界

- 不说「命中注定」「寿数」「某年有血光之灾」之类的话；凶的组合只说「宜谨慎」。
- 女命不作贞洁、品行之类的断语。《三命通会》部分神煞条文带有这类说法，不转述。
- 用户有焦虑时，说明命理是传统文化中的一种推演，人生决定以现实情况为准。

## 七、只给四柱、没有出生时间时

用户直接给出四柱（如古籍命例）时无法调用 `bazi`，可直接据四柱论断；需要大运时，按「阳年男、阴年女顺排，阴年男、阳年女逆排，自月柱起」排干支，并说明起运岁数需出生时刻才能算。
查表规则（十神、藏干、合冲刑害、神煞）以本 skill 的规则资料为准，《穷通宝鉴》原文可按日干、月令说出所在章节，但不要凭记忆背诵原文。
