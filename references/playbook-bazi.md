# 八字流程

适用：八字排盘、日主强弱、用神，以及八字配合风水（旺方、卧室书桌方位）。先读完本文件再作答。

## 一、分析流程

**必要信息**：出生年月日时（北京时间）、性别，最好有出生地经度（真太阳时）。

```
1. bazi --birth "..." --gender ... [--longitude ...]
2. 依月令、通根、透干判断日主强弱（这是判断，需说明理由）
3. 定喜用五行 → 对应方位、五色建议（五行方位、五色见规则资料 wuxing-ganzhi.md；不要给「材质」建议，查无出处）
4. 结合命卦给出卧室、书桌方位建议
```

八字非本 skill 核心，结论宜谨慎，避免下「命中注定」之类的断语。

## 二、只给四柱、没有出生时间时

用户直接给出四柱（如古籍命例）时无法调用 `bazi`，可直接据四柱论断；需要大运时，按「阳年男、阴年女顺排，阴年男、阳年女逆排，自月柱起」排干支，并说明起运岁数需出生时刻才能算。
