# 择日学速查

> 具体日期的干支、建除、神煞、宜忌一律用 `scripts/fengshui.py day` / `zeri` 查询，本文件仅供理解规则。不要凭本表心算具体某天。

## 一、常用事项择日要点

### 入宅 / 乔迁

**吉神宜见**：天德、月德、天德合、月德合、母仓、生气、益后
**凶神宜避**：岁破、月破、三煞、大煞、归忌、受死、往亡

吉日倾向：成日、开日（建星）、满日次之
入宅方向：从宅主命卦生气方入门最吉

### 开业 / 开市

**吉神宜见**：天德、月德、开日、成日、定日
**凶神宜避**：月破、岁破、受死日、闭日

注：开业与财有关，向星旺位（飞星中当令向星所在位）宜开门见水（路、停车场亦可）

### 动土 / 装修 / 改建

**最重要**：
1. 避太岁方（当年太岁所在方位）
2. 避三煞方（见下表）
3. 避五黄方（流年五黄所在位）
4. 避岁破月破日

**三煞方**（每年轮换）：

| 年份（地支）| 三煞方 |
|-----------|--------|
| 申子辰年 | 南方（巳午未）|
| 寅午戌年 | 北方（亥子丑）|
| 亥卯未年 | 西方（申酉戌）|
| 巳酉丑年 | 东方（寅卯辰）|

2024年（甲辰年）→ 申子辰年 → 三煞在南
2025年（乙巳年）→ 巳酉丑年 → 三煞在东
2026年（丙午年）→ 寅午戌年 → 三煞在北

### 婚嫁 / 嫁娶

**吉神宜见**：天德、月德、天恩、吉庆、成日、开日
**凶神宜避**：月破、岁破、往亡、正四废、红沙日

注：婚嫁最重男女双方八字合婚，择日次之；双方本命年（值太岁）宜简礼

### 安葬 / 阴宅动工

**吉神宜见**：天德、月德、成日、开日
**凶神宜避**：月破、岁破、三煞、重日（重复凶）、建日

注：阴宅讲究山水形势重于择日，峦头不吉，日子再好收效甚微

## 三、每月月破日

月破即建除中的「破」日：日支冲月建。月份以**节气**为界（交「节」换月），不是农历初一。

| 节气月（月建）| 月破日（地支）|
|-----------|-------------|
| 寅月（立春—惊蛰） | 申日 |
| 卯月（惊蛰—清明） | 酉日 |
| 辰月（清明—立夏） | 戌日 |
| 巳月（立夏—芒种） | 亥日 |
| 午月（芒种—小暑） | 子日 |
| 未月（小暑—立秋） | 丑日 |
| 申月（立秋—白露） | 寅日 |
| 酉月（白露—寒露） | 卯日 |
| 戌月（寒露—立冬） | 辰日 |
| 亥月（立冬—大雪） | 巳日 |
| 子月（大雪—小寒） | 午日 |
| 丑月（小寒—立春） | 未日 |

## 四、正四废

以节气月所在季论：春（寅卯辰月）庚申、辛酉日；夏（巳午未月）壬子、癸亥日；秋（申酉戌月）甲寅、乙卯日；冬（亥子丑月）丙午、丁巳日。

## 五、岁破与太岁

**太岁方**：当年地支对应方位（年份以立春为界），忌动土、施工

| 年份 | 年干支 | 太岁方 |
|------|--------|--------|
| 2024 | 甲辰 | 东南（辰）|
| 2025 | 乙巳 | 东南（巳）|
| 2026 | 丙午 | 南（午）|
| 2027 | 丁未 | 西南（未）|
| 2028 | 戊申 | 西（申）|

**岁破**：太岁对冲方，同样忌动土
（如2026年午年，岁破在北方子位）
