# 择日学速查

> 具体日期的干支、建除、神煞、宜忌一律用 `scripts/fengshui.py day` / `zeri` 查询，本文件只说明规则。不要凭本表心算某一天。
>
> 出处与核对状态见 [sources.md](sources.md)。择日体系以清代官修《钦定协纪辨方书》为正统；本次未能取得该书原文（📖），
> 能用独立数据交叉验证的项目已验证（🧮）。通书中的民间做法另标 ⚖，不与《协纪》混同。

## 一、月份以节气为界

择日所用的「月」是**节气月**：交「节」（立春、惊蛰、清明……）即换月，月建依次为寅、卯、辰……丑。不是农历初一换月。

| 月建 | 起止 |
|------|------|
| 寅 | 立春—惊蛰 |
| 卯 | 惊蛰—清明 |
| 辰 | 清明—立夏 |
| 巳 | 立夏—芒种 |
| 午 | 芒种—小暑 |
| 未 | 小暑—立秋 |
| 申 | 立秋—白露 |
| 酉 | 白露—寒露 |
| 戌 | 寒露—立冬 |
| 亥 | 立冬—大雪 |
| 子 | 大雪—小寒 |
| 丑 | 小寒—立春 |

年份同理以**立春**为界。

## 二、大忌（脚本硬性排除）

### 月破

出处：《协纪辨方书》📖；🧮 与 lunar-python 凶煞「月破」逐日一致（3 年）

即建除十二神中的「破」日：日支冲月建。寅月申日、卯月酉日、辰月戌日……丑月未日。

### 正四废

出处：《协纪辨方书》📖；🧮 与 lunar-python 凶煞「四废」逐日一致（3 年）

以节气月所在季论：春（寅卯辰月）庚申、辛酉日；夏（巳午未月）壬子、癸亥日；秋（申酉戌月）甲寅、乙卯日；冬（亥子丑月）丙午、丁巳日。

### 冲当事人

日支与当事人生年地支相冲（六冲见 [wuxing-ganzhi.md](wuxing-ganzhi.md)，《三命通会》✅）。

### 黄历明忌

当日宜忌中明列「忌」该事项。宜忌数据取自 lunar-python（⚖，其文档未说明出处）。

## 三、通书俗忌（脚本只标注 △，不排除）

以下两项为通书常用，但不在《协纪辨方书》体系的日神之列（lunar-python 的日凶煞中亦未列）。
脚本照常列出候选日，并标注「通书俗忌」，由你向用户说明，让用户自行决定。

| 俗忌 | 规则 |
|------|------|
| 岁破日 | 日支冲太岁（年支） |
| 受死 | 依节气月取一支，凡该支之日皆是，约每 12 天一次：寅月戌、卯月辰、辰月亥、巳月巳、午月子、未月午、申月丑、酉月未、戌月寅、亥月申、子月卯、丑月酉 |

不再收录：红沙日等其他通书俗忌（✂）。

## 四、建除十二神

出处：《协纪辨方书》📖

以节气月建起：月建之日为「建」，其后依次为除、满、平、定、执、破、危、成、收、开、闭。

脚本择日时以成、开为首选，满、定等为次选（各事项略有不同）。这是本项目的筛选启发式 ⚖，不是古法明文。
**不再收录**每个建除神的逐项宜忌表：那是通书口径，各本不一 ✂。具体某日宜忌以 `day` 命令输出为准。

## 五、年神方位（动土、修造须避）

出处：《协纪辨方书》年神方位 📖

| 年神 | 规则 | 例：2026 丙午年 |
|------|------|----------------|
| 太岁 | 年支所在之山 | 南（午山） |
| 岁破 | 太岁对冲之山 | 北（子山） |
| 三煞 | 申子辰年在南（巳午未），寅午戌年在北（亥子丑），亥卯未年在西（申酉戌），巳酉丑年在东（寅卯辰） | 北（亥子丑） |
| 流年五黄 | 年紫白五黄所到之宫（见 [feixing.md](feixing.md)） | 南 |

用 `liunian --year <年>` 查询任一年。

## 六、吉神

出处：神煞名目见《协纪辨方书》📖；当日有哪些吉神取自 lunar-python（⚖）。

脚本打分时看重天德、月德、天德合、月德合、天赦、天恩、母仓。各吉神能「解」哪些凶煞，《协纪辨方书》有专门规定，本次未核对原文，
所以**不要对用户说「某吉神可解诸凶」之类的话**，只说明当日有哪些吉神、哪些凶煞。

## 七、各事项要点

以下为通行做法 ⚖，脚本 `zeri --event` 已据此设定关键词与建除偏好：

| 事项 | 黄历宜忌关键词 | 建除偏好 | 另须注意 |
|------|------------|---------|---------|
| 入宅 / 搬家 | 入宅、移徙 | 成、开；次满、定 | — |
| 开业 | 开市、立券、交易 | 开、成；次满、定 | — |
| 动土 / 装修 | 动土、修造 | 成、开；次定 | 避年神方位（第五节） |
| 嫁娶 / 订婚 | 嫁娶；订盟、纳采 | 成、开；次定、满 | 传统以双方八字合婚为先，择日次之 |
| 安葬 | 安葬、破土 | 成、开；次除 | 《葬书》以形势为本（✅「葬者乘生氣也」） |
| 出行、签约、安床 | 出行；立券、交易；安床 | 依事项 | — |
