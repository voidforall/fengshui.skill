## 五行生克

**相生**（母子关系）：
```
木 → 火 → 土 → 金 → 水 → 木（循环）
```

**相克**（制约关系）：
```
木 → 土 → 水 → 火 → 金 → 木（循环）
```

**比和**：同五行，力量相加（旺者更旺，弱者得助）

**相泄**：生出去为泄（木泄于火，火泄于土……）

## 命卦计算

> 实际计算请用 `scripts/fengshui.py mingua --birth YYYY-MM-DD --gender m/f`，会自动按立春分年。

**年份以立春（约 2 月 4 日）为界**：1 月或 2 月初立春前出生者，按上一年计算。

公式（适用于任何世纪）：

- 男命：`(11 − 年 mod 9) mod 9`，结果 0 作 9；**得 5 寄坤（2）**
- 女命：`(年 mod 9 + 4) mod 9`，结果 0 作 9；**得 5 寄艮（8）**

等价的传统速算（1900–1999 年）：男命 `(100 − 年后两位) mod 9`，女命 `(年后两位 − 4) mod 9`；
2000 年后：男命 `(99 − 年后两位) mod 9`，女命 `(年后两位 − 3) mod 9`。

## 地支六合、三合

**六合**（感情和谐）：
子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合

**三合局**（力量汇聚）：
- 申子辰合水局
- 亥卯未合木局
- 寅午戌合火局
- 巳酉丑合金局

**三刑**（冲突）：
寅巳申三刑、丑戌未三刑、子卯相刑、辰午酉亥自刑

**六冲**（对冲）：
子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲

> 风水用途：太岁（流年地支）与宅主命支相冲，当年注意宅运流年不利。
