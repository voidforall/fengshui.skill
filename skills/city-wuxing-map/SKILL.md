# 城市区域五行地图

交付可缩放的真实地图，**区域半透明着色是主视图**，地标是默认隐藏的证据层。用户要认识“一整片区域偏什么相”，应解释区域整体格局，不能用一个银行、公园或剧院的标签代替。

## 研究与划区

1. 明确城市、国家与观察范围。只给城市名时，选择一组有依据的代表片区，说明未覆盖处尚未收录。同名城市先确认国家。
2. 先读 [分析方法](references/method.md)，区分山水形态取象与城市功能类比；需要传统形法时须说明所用原典，不能把现代生态或行业类比冒称古法。
3. 联网核对景观单元、水系、地形、街网、建筑群或功能集群，优先政府、景观评估、管理机构与公开地图。区界优先取可靠的 GIS 边界；若依据地图、河道、道路与资料手工划定，标为**解释性概化**，写清范围、为什么如此划分及原始来源。不能把 PDF 示意图称为已取得精确矢量边界。
4. 每区研究整体特征，再给主象与兼象；允许过渡、混合和暂缺结论。没有相关分析的方法视图显示灰色待分析，不自动借用另一种口径，也不为凑五色编造理由。不要用地标等半径圆、行政区名字或市中心方位代替区域分析。
5. 按 [区域数据格式](references/data-format.md) 写 JSON：GeoJSON Polygon/MultiPolygon 几何、边界来源、每种口径的事实与理由、主象/兼象、局限以及可选证据点。坐标为 WGS84，经度在前；空间轮廓须人工核对。无法联网时只能使用内置已附来源的数据或用户提供资料，不能虚构新区界。

## 生成与交付

以下路径相对本 skill 目录；实际使用时将脚本路径换为本目录绝对路径，输出写到用户工作目录：

```bash
python3 scripts/generate.py --example london --output 伦敦区域五行地图.html
python3 scripts/generate.py --example new-york --output 纽约区域五行地图.html
python3 scripts/generate.py --input 城市区域.json --output 城市区域五行地图.html
```

- 生成器用 Python 标准库校验区域结构与基本坐标，不负责自动研究或推断区界。旧版 `places` 点位数据须补齐区域与证据链，不能自动扩成色块。
- HTML 内嵌 Leaflet 与许可，无需 npm 或 API key；真实瓦片需联网并通过 HTTP 访问。在输出目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，访问对应文件名；有服务则复用。直接双击 HTML 时只显示区域分析，页面提示改用 HTTP。
- 用浏览器检查真实底图、片区多边形位置、点击色块与索引联动、主象兼象、方法切换、灰色待分析、证据层、搜索和手机布局。结合实际道路河岸检查概化范围，不把渲染成功视为地理正确的证明。不要批量预下载瓦片。
- 回复开头提供地图链接及原始 JSON，说明覆盖范围、资料日期和区界性质。若本地服务未保持运行，给启动命令，不交付失效的本地 URL。区界表示分析范围，不是五行影响的硬边界；不报未经定义和验证的能量数值或百分比。

## 示例

- `examples/london.json`：泰晤士河中心河谷、Hampstead 林地山脊、Bloomsbury 方整街坊、West End 演艺区、City 金融核心、Canary Wharf 港池商务片，共6区。Canary Wharf 分别记录水岸结构与金融功能，在两种口径下有不同主象。
- `examples/new-york.json`：Central Park 绿地整体、Hudson 下城西岸走廊、Lower Manhattan 金融商务片、Broadway 剧院街区、Bryant–Midtown 规则街坊，共5区。

两套示例区界都是有说明的手工概化观察范围，并非法定或官方风水区。日期为资料核对日期，重新生成不代表已更新事实。复制到用户工作目录再编辑，不改安装目录中的示例。
