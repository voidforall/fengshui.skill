# 城市五行风水地图

交付可缩放、可筛选五行、可点击查阅依据的真实城市地图，附可编辑的地点 JSON。地图以地理事实为底、五行文化解读为标注；不凭城市名称生成任意色块，不把点位画成未经证实的片区边界。

## 从需求到地图

1. 确定城市与范围。用户只说城市时，默认选中心城区及有代表性的周边地点，明确覆盖范围；同名城市需先确认国家。无需为未请求的八字、朝向或入住年份提问。
2. 先读 [五行取象与事实规范](references/method.md)。通过可用的联网检索或地图工具核对河流、园林、山丘、地标及城市功能；优先政府、地图、管理机构与场馆官网。不能联网时，使用已附来源的示例或用户提供的已核对数据，明确资料日期，不能虚构其他城市坐标。
3. 按 [输入格式](references/data-format.md) 整理 JSON。每处地点写真实 WGS84 经纬度、单一主五行、取象类型、地理事实、五行解读与事实来源。可在解读中说明兼具其他五行。不为凑齐五行捏造地貌或功能；资料不足时说明缺项。
4. 调用本 skill 自带生成器。它校验数据并嵌入地图模板，不负责联网研究，也不会把官方事实自动判成风水结论。`--input` 支持任意城市；`--example` 只选内置资料。

以下路径均相对于本 skill 目录；实际调用时将脚本路径替换为该目录的绝对路径，输出写到用户工作目录：

```bash
python3 scripts/generate.py --example london --output 伦敦五行地图.html
python3 scripts/generate.py --example new-york --output 纽约五行地图.html
python3 scripts/generate.py --input 城市地点.json --output 城市五行地图.html
```

5. 在**输出目录**启动本地静态服务，例如 `python3 -m http.server 8000 --bind 127.0.0.1`，通过对应 `http://127.0.0.1:8000/文件名.html` 打开。已有本地服务则复用。HTML 已内嵌 Leaflet，无需 npm、API key 或 Python 第三方包；真实底图仍需联网。直接以 `file://` 打开时仅可查阅标注，页面会提示改用 HTTP，不发出缺少 Referer 的 OSM 瓦片请求。
6. 有浏览器工具时，检查真实河道、道路与地名已出现，标记落在合理位置，五行筛选、搜索、列表与地图点击同步，手机可读且无横向溢出。地图服务失败时保留错误提示，不能把空背景截图当作真实地图完成证据。不要为了截图批量抓取或预下载瓦片。
7. 回复开头给出可访问的地图链接，并附原始 JSON 路径，概述标注范围、代表地点及资料日期。说明它是五行取象导览，底图联网；若服务未保持运行，则给出可复现的启动命令，不承诺一个失效的本地 URL。

## 内置示例

- `examples/london.json`：10 个代表点。金为英格兰银行与 Canary Wharf；木为海德公园与邱园；水为泰晤士河塔桥段与小威尼斯；火为环球剧场与皇家歌剧院；土为 Primrose Hill 与格林尼治山丘。
- `examples/new-york.json`：NYSE、中央公园林地、炮台公园水岸、林肯中心与 Vista Rock，展示另一座大城市及不同经纬度下的同一生成流程。

示例事实按文件内日期核对，坐标为手工选择的代表位置。重新生成不意味着重新核实了最新事实；用户要求现状时仍要查证。不要改动已安装的示例来生成用户专属版本，复制到用户工作目录后编辑。
