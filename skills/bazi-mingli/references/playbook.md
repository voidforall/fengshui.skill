# 八字流程

适用：排八字、日主强弱与喜用、「我五行缺什么」、大运流年、事业财运婚姻等倾向、神煞（桃花、驿马、贵人），
以及八字配合风水（旺方、卧室书桌方位）。先读完本文件再作答。

结论宜谨慎，只说倾向，不说「命中注定」。

## 一、问询：先把出生时间问准

时柱错一个时辰，十神、大运起运都会变。排盘前问清：

| 要问 | 为什么 | 对应参数 |
|------|-------|---------|
| 出生日期：公历，或农历（问清是否闰月） | 农历由脚本换算，不要自己换 | `--birth`；农历加 `--lunar`，闰月再加 `--leap` |
| 出生时间：当时钟表上的时间，几点几分 | 不知道就只给日期，脚本排三柱 | `--birth "YYYY-MM-DD HH:MM"` 或只写日期 |
| 性别 | 大运顺逆 | `--gender m/f` |
| 出生城市 | 经度定真太阳时；海外要时区 | `--longitude`（东经为正、西经为负）；海外加 `--tz America/New_York` 之类 |

- 城市的经度可以按常识给出（如上海 121.5、北京 116.4、广州 113.3、成都 104.1、乌鲁木齐 87.6），说明是城市中心近似值。
- **夏令时不用问、也不要自己扣**：脚本按时区数据库自动处理（中国大陆 1986–1991 年夏季钟表快一小时）。用户说「已经减过一小时」时，把减之前的钟表时间给脚本。
- **23 点后出生**：脚本默认 23:00 起换日，并列出另一派（晚子时日柱不换）的日柱、时柱。向用户说明两说并存；用户或家里一直按另一种排，就加 `--zi same`。
- 用户只说「早上」「半夜」这类时段时：先按日期排三柱，再说明时柱有哪几种可能，不要替用户挑一个时辰。

## 二、排盘

```bash
python3 scripts/bazi.py --birth "1990-06-01 08:30" --gender f --longitude 116.4 \
        [--tz Asia/Shanghai] [--zi next|same] [--year 2027] --html <路径> [--notes 批注.json]
```

- 默认就生成交互命盘（`--html`），写到用户当前工作目录。问「某年怎么样」时加 `--year 年份`，盘面和文字都会落在那一年。
- 输出里都是计算或查表的事实：四柱、十神、藏干（本气、中气、余气及十神）、十二长生、纳音、旬空、月令司令（《三命通会》人元司事）、
  通根、透干、原局合冲刑害、五行个数、查表神煞、《穷通宝鉴》调候原文、起运、十步大运及其中的流年、关注年份的流年。
- **这些一律以脚本为准**，不要自己推干支、节气、十神，也不要补脚本没给的神煞。
- 输出开头若有「⚠」提示（23 点后出生、时辰不详、当日交节等），回答时必须告诉用户。

## 三、论命：判断要写出依据

旺衰、格局、用神不由脚本给出，是你的判断。主要依《滴天髓阐微》（任铁樵）的论法，其原文已核对（见 sources.md）。
按下面顺序看，每一步写出依据；先把八个字的力量看清，再谈喜用。

1. **调候原文**：读脚本给的《穷通宝鉴》原文（按日干、月令检出），照录，不要改写成原文没有的「用某某」。
   原文标为「季论」的，表示书中本月没有专段，只能参考一季总论。调候是一项参考，不自动等于用神（见第 5 步）。
2. **季节有虚实，得令未必旺**：任氏：「得时俱为旺论，失令便作衰看，虽是至理，亦死法也。」
   「春木虽强，金太重而木亦危」，「秋木虽弱，木根深而木亦强」。春土、冬土气虚，夏水、冬火无根即弱，
   不能只凭「当令」二字定强，也不能只凭「失令」定弱。
3. **根气轻重**：看脚本「通根」一栏的重根、轻根。任氏：「只要四柱有根，便能受财官食神而当伤官七杀」；
   「天干得一比肩，不如地支得一余气墓库」，「得二比肩，不如支中得一长生禄旺」。天干比劫多而地支无根，仍是虚。
4. **克泄耗合起来看**：把克日主（官杀）、日主所生（食伤）、日主所克（财）三方合起来，与生日主（印）、同日主（比劫）相比。
   日主有根、却被食伤财官层层泄耗时，往往是「旺中有衰」；日主失令、但根深印重时，是「衰中有旺」。
   合、冲改变力量时要说明：合而化须有条件，脚本只标合；三合只见两字不成局。
5. **寒暖燥湿**：看脚本「寒暖燥湿」一行。原文：「寒虽甚，要暖有气，暖虽至，要寒有根」；
   「过于湿者，滞而无成；过于燥者，烈而有祸」；「木火伤官要湿也」「金水伤官要燥也」。
   燥土（未戌）「助火而不能晦火」，湿土（辰丑）「助水而不能制水」。
   调候之神是让局面成形的条件，常作喜神；只有当它同时是日主最需要依赖之神时才是用神，要说清是哪一种。
6. **旺极、衰极与从**：先看是不是「可抑」「可扶」。任氏：「旺则抑之，如不可抑，反宜扶之；弱则扶之，如不可扶，反宜抑之」，
   「旺极者抑之，抑之反激而有害，则宜从其强而扶之；弱极者扶之，扶之徒劳而无功，则宜从其弱而抑之」。
   五行颠倒之理，如「木太旺者而似金，喜火之炼也；木旺极者而似火，喜水之克也」，其余四行仿此（见 sources.md）。
   真从要「日主孤立无气，无地人元，绝无一毫生扶之意」；有一点生扶就不是真从，按扶抑论或论假从。
   满局一气（从旺、从强）、气势偏于两行（从气）、财官食伤并旺而日主无根（从势），各有所喜，详见 sources.md。
7. **定用神**：任氏：「用神者，日主所喜，始终依赖之神也」。按日主与各方力量对比取用：

   | 情形 | 用神 |
   |------|------|
   | 日主旺，印绶多 | 财星 |
   | 日主旺，官杀轻 | 财星 |
   | 日主旺，比劫多 | 食伤 |
   | 日主弱，官杀旺 | 印绶 |
   | 日主弱，食伤多 | 印绶 |
   | 日主弱，财星旺 | 比劫 |
   | 日主与官杀两停 | 食伤 |
   | 日主与财星均敌 | 印比 |

   以上依《滴天髓阐微》「体用」任注。任氏又说「总之有用无用，定有一个着落」：**用神要落在原局实有、有根可用的字上**。
   局中没有、或虚浮无根的五行，即使按表应取，也只能作喜神、盼运来补，不能作主用神；这时退而取局中能依靠的那一行
   （如该用印而局中无印，日主又被泄耗，就看比劫能否帮身）。只管暖局、润局的调候之神同理（第 5 步）。
   明确写出「用神：某（干支或五行）」，只有一个主用神，其余写成喜神、忌神，
   不要把主用神降成喜神。若用神取的是某一个字（如时上丙火、卯中乙木），写出是哪一个字、为什么是它。
8. **对照《穷通宝鉴》**：调候原文与上面的结论一致时，一并引用；不一致时并列两说，说明此盘以哪个为先、为什么。
   调候派、扶抑派、格局派结论不同时，不要强行统一。

## 四、写给不懂命理的人：先白话，后专业

大多数用户不懂术语。除非用户自己说「我懂命理」「说专业一点」，回答一律按这个结构：

1. **一句话结论**，不用术语。如「你的盘里『你自己』和『钱财』两边都有力量，比较均衡」。
2. **你的盘像什么**：日主的物象（规则资料 glossary.md「天干物象」，《三命通会》原文）和出生季节的强弱（脚本「旺相休囚死」一行）。
   如「你是丁火，古书说丁火『在天为列星，在地为灯火』；你生在初夏，正是火最旺的时候」。
3. **为什么**：两三条关键理由，每条一句白话。必须用术语时，第一次出现就在括号里解释，释义以 glossary.md 为准，
   如「正印（生你的字，代表学习、庇护）」「通根（地支里有同类的字撑着，好比树有根）」。
4. **这几年、今年**：说倾向和可以怎么做，如「宜稳中求进」，不说吉凶定论。
5. **专业依据**放在最后一段，标明「专业依据」：月令、通根透干、调候原文、所依派别。用户追问时再展开。

不要：

- 开头就列四柱、十神表；
- 一句话里堆三个以上术语；
- 把「死」「绝」「病」「羊刃」「七杀」这类术语名当判断说出口。它们只是名称，要换成白话，如「日主在这里气势最弱」「这是带来压力、也带来魄力的字」；
- 把十神说成命定（「有七杀所以一定压力大」），只说倾向。

## 五、按用户问的问题作答

| 用户问的 | 怎么答 |
|---------|-------|
| 「我五行缺什么」 | 先给脚本的两组个数（天干地支、藏干），说明「缺」只是字数上没有，不等于需要补；再按第三节判断，给出喜用。 |
| 喜用神、旺衰 | 按第三节完整论述。 |
| 今年、某年运势 | 用 `--year`。看流年干支的十神、与原局和所行大运的合冲刑害，再结合喜忌说倾向。不说具体灾祸，不说「必有」。 |
| 大运走势 | 按脚本的十步大运逐步说：干支十神、日干长生、与原局关系，再结合喜忌。 |
| 事业、财运、婚姻 | 只按十神和喜忌说倾向（如财星为喜、运行财地）。婚姻不说「克夫」「克妻」「婚姻必破」。 |
| 健康 | 只说五行偏枯的传统说法，并建议就医，不作诊断。 |
| 桃花、驿马、贵人、空亡 | 用脚本的查表结果，并转述《三命通会》「见生旺者未必便作吉论，见休囚死绝未必便作凶言」：神煞不单独定吉凶。脚本没列的神煞，说明本 skill 未核对出处。 |
| 八字配风水 | 喜用五行 → 方位、五色（见规则资料 ganzhi.md；不给「材质」建议，查无出处）。脚本输出的命卦属八宅，是另一套方法；宅命配合、卧室朝向请转用 fengshui-master，两者冲突时说明是两种体系，以实际居住条件为先。 |
| 合婚、起名 | 本 skill 没有核对过出处的合婚、起名规则，也没有计算。可以讲原理，要说明是通行说法，不下「不能结婚」之类的结论。 |

## 六、交互命盘

排了八字就默认生成命盘。四柱以卡片依次翻开，柱间弧线标合冲刑害，点任一干支看通根、透干、藏干与关系；
下方大运流年可点选或拖动，落到某一年就显示该年与原局的关系。

页面最上方是「一眼看懂」：你写的 `plain`（白话总结），以及脚本给出的日主物象、出生季节强弱、五行个数、当前大运流年。
页面上每个术语都可以点开看白话解释（与 glossary.md 一致），还有「白话」开关在命盘上标出十神、长生的一词释义。

你的解读写成批注 JSON，用 `--notes` 传入（所有字段可选，只写文字，不写干支计算）：

```json
{
  "plain": "白话总结：一句话结论、为什么、这几年，三四段，不用或少用术语（按第四节写）",
  "basis": "调候依《穷通宝鉴》四月丁火条；旺衰按子平月令、通根、透干",
  "summary": "专业版总断：旺衰、格局、用神及理由",
  "pillars": {"年": "……", "月": "……", "日": "……", "时": "……"},
  "dayun": {"戊寅": "这步大运的看法（白话为主，术语括注）"},
  "years": {"2026": "这一年的看法（白话为主，术语括注）"},
  "advice": ["一条建议", "……"]
}
```

生成后，**回答的开头必须给出链接**：`[打开命盘](file:///脚本打印的绝对路径)`，并用一句话说明可点干支、拖动年份。

## 七、表达边界

- 不说「命中注定」「寿数」「某年有血光之灾」之类的话；凶的组合只说「宜谨慎」。
- 女命不作贞洁、品行之类的断语。《三命通会》部分神煞条文带有这类说法，不转述。
- 用户有焦虑时，说明命理是传统文化中的一种推演，人生决定以现实情况为准。

## 八、只给四柱、没有出生时间时

用户直接给出四柱（如古籍命例、只记得八字）时，用 `--pillars`，不要为了调用脚本去反推一个出生日期：

```bash
python3 scripts/bazi.py --pillars "庚申 庚辰 戊辰 戊午" --gender m
```

输出四柱十神、藏干、十二长生、纳音、通根（标重根、轻根）、透干、合冲刑害、寒暖燥湿、查表神煞、《穷通宝鉴》调候原文，
以及自月柱起排的大运干支（不需要历法库）。起运岁数、流年周岁需要出生时刻，此时不给；不生成交互命盘。
论命仍按第三节，事实以脚本为准。
